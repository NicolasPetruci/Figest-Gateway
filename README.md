# Figest Gateway

API Gateway for the Figest application.

## Development

```bash
npm install
npm run dev
```

## Environment Variables

- `PORT` (default: 3000)
- `USUARIO_SERVICE_URL` (default: http://localhost:3001)
- `FINANCEIRO_SERVICE_URL` (default: http://localhost:3002)
- `COMPRAS_SERVICE_URL` (default: http://localhost:3003)
- `RELATORIO_SERVICE_URL` (default: http://localhost:3004)
- `INTEGRACAO_SERVICE_URL` (default: http://localhost:3005)

## Build & Run

```bash
npm run build
npm start
```
